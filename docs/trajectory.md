# 轨迹质量检测

检测器移植自 `footprint-serverless` 的 `excursion-v3-experimental`. 输入为 WGS84 坐标和观测时间, 输出是候选质量标记, 不删除位置、不替换坐标.

## 判定规则

- 同设备按时间与 ID 排序. 同时同坐标的点只在计算中合并, 最终传播标记到重复记录; 同时不同坐标的观测标为不确定并切断推断.
- 短窗口两端跨度不超过 30 分钟, 中间最多 8 点. 使用球面距离和速度约束寻找固定两端、保留点数最多的路径, 相同数量时选择距离更短的路径.
- 候选必须偏离两侧保留点之间的时间插值位置至少 1 km, 且绕行比至少为 4. 邻近观测用来检查两端是否可信, 避免把错点当作正常锚点.
- 局部速度上界为 `max(150, 3 * 两端速度 + 30, 3 * 外侧支持平均速度 + 30)` km/h. 进出速度均至少达到 `max(500, 局部上界)`, 且两侧都有可信支持时标为高置信候选.
- 超过短窗口限制时, 最多允许 3 小时的往返, 两端相距不超过 1 km, 进出速度至少一侧超过 1500 km/h, 并要求外侧位置支持. 合理的高速行程不会仅因速度高而被标为异常.
- 候选择优并保护保留点和锚点, 最多执行 3 次高置信候选虚拟移除. 没有足够证据归因的极端跳变保留为不确定.

## 实时处理与并发

每次录入先在事务内保存位置和 `pending` 标记, 再读取同设备前后各最多 64 个点. 两侧另读截断哨兵, 实际参与分析最多 129 点. 设备版本、位置和原有标记通过同一个可重复读事务获取.

通常重算录入点前后各最多 27 点, 同时覆盖窗口内相关的完整重复组和时间冲突组. 上下文被截断时使用保守标记. 只写回状态、原因、算法版本或证据发生变化的标记.

写回事务锁定设备版本记录, 只有版本仍与读取快照一致才保存结果. 无变化的分析也检查版本. 版本变化时重新读取并分析, 最多尝试两次, 防止较旧请求覆盖较新上报的结果.

| 状态 | 含义 |
| --- | --- |
| `pending` | 等待后续观测 |
| `retained` | 当前窗口未检测到偏离 |
| `outlier` | 规则支持较强的候选 |
| `review` | 待复核候选 |
| `uncertain` | 时间冲突、采样缺口、未归因跳变或上下文不足 |
| `unassessed` | 尚无质量标记 |

API 的 `view=filtered` 只排除 `outlier`, 其他状态保留. 后续上报或补报可以修改已有标记.

## 历史匹配

几何判定完成后, 为候选查找同设备至少早 24 小时、距离不超过 100 米的历史观测. 历史参考须已保留, 或在本次窗口中被判为保留, 并排除当前已知异常.

先用经纬度包围盒和索引筛选, 再计算球面距离. 日期变更线范围分拆, 极区覆盖全部经度. 每次分析尝试最多查询 2 个候选, 每个返回最多 64 条原始参考及一条截断哨兵, 再检查参考质量.

匹配只提供辅助证据, 不产生异常或提高异常等级. 候选段未变化时复用已完成的历史证据; 补报、段落变化或参考在当前窗口被判为异常时重新查询. 历史查询失败、候选预算耗尽或结果截断时明确记录不完整状态.

## 限制

原始位置已提交后, 分析失败仍返回录入成功, 并报告 `analysis.state=deferred`. 后续邻近上报可以触发重算, 当前没有独立重试队列或定时补算.

局部窗口不能保证与离线全量分析一致. 长错误定位簇、缺少返回证据、超出 3 小时的往返、窗口边界、小于 1 km 的漂移或速度仍合理的错点可能漏检. 历史证据缓存也可能滞后于窗口外的数据变化.

这些标记是实验规则的结果, 不代表人工确认的位置真值. 检查轨迹时可以同时查询原始视图.
